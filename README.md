# Raj Cloud Consulting — Corporate 3D Edition

Static, responsive GitHub Pages website for **RajCloudConsulting.com**.

## Highlights
- Animated CSS 3D cloud architecture hero
- No portrait in the homepage hero
- Interactive cloud topology
- 3D security visual
- Founder portrait only in the About section
- Responsive and reduced-motion support
- SEO metadata, sitemap and GitHub Pages workflow

## Deployment
Upload the extracted contents to the root of:
`rajcloudconsulting/raj-cloud-consulting`

Keep:
`.github/workflows/pages.yml`

Commit to `main`; GitHub Actions will redeploy the site.

## Privacy
Do not publish tenant IDs, subscription IDs, internal hostnames, IP addresses, employer/client names, secrets, tokens or confidential certificates.
