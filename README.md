## Before publishing

Search and replace these placeholders:

- `rajcloudconsulting`
- `rajcloudconsulting@gmail.com`
- `rajcloudconsulting`
- Example premium checkout URLs

## Publish with GitHub Pages

1. Create a public GitHub repository named `raj-cloud-consulting`.
2. Upload all files from this folder into the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **GitHub Actions**.
5. The included workflow will deploy the website.
6. Your site will appear at:

   `https://rajcloudconsulting.github.io/raj-cloud-consulting/`

## Local preview

Open `index.html` directly, or run:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000`.
