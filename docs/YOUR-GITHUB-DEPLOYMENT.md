## Browser upload method

1. Open the repository.
2. Select **Add file → Upload files**.
3. Upload everything from this project folder.
4. Confirm `index.html` is visible at the repository root.
5. Commit to the `main` branch.
6. Open **Settings → Pages**.
7. Select **GitHub Actions** as the publishing source.
8. Open the **Actions** tab and wait for the deployment to complete.

## Git command method

```powershell
git clone https://github.com/rajcloudconsulting/raj-cloud-consulting.git
cd raj-cloud-consulting
# Copy the website files into this folder.
git add .
git commit -m "Publish Raj Cloud Consulting website"
git push origin main
```
