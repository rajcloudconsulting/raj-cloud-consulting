# GitHub Pages Setup

1. Create a public repository named `raj-cloud-consulting`.
2. Upload the contents of this project so `index.html` is at the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **GitHub Actions**.
5. Wait for the included Pages workflow to complete.
6. Replace all placeholder values:
   - `rajcloudconsulting`
   - `rajcloudconsulting@gmail.com`
   - `rajcloudconsulting`
7. Test the website and all script links.

The Azure Portal dashboard is a visual portfolio component. It uses static example data and does not connect to any Microsoft tenant.
